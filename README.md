# Forest

这是一个基于 Unity 的小型交互演示项目，当前核心玩法是“蘑菇汤制作”。玩家通过键盘控制火力、投放蘑菇、进行搅拌，按步骤完成整道烹饪流程。

项目定位更偏向课程展示、功能演示和原型验证，特点是结构简单、交互完整，并且可以通过脚本自动搭建玩法所需的场景对象和 UI。

## 开发环境

- Unity：`2022.3.62f3c1`
- 解决方案：`Forest.sln`
- 主要 UI 方案：`UnityEngine.UI`

## 项目结构

当前和玩法直接相关的核心内容主要在下面几个位置：

- `Assets/Scenes/SampleScene.unity`
  - 示例场景
- `Assets/Scripts/Cooking/MushroomSoupSceneBootstrap.cs`
  - 负责初始化场景、创建锅、火焰、汤面、搅拌勺、蘑菇投放点和 UI
- `Assets/Scripts/Cooking/MushroomSoupGame.cs`
  - 负责处理输入、火力变化、烹饪进度、状态切换、动画和界面刷新

其余目录中的资源主要是锅、蘑菇、树木、自然场景和其他素材包，用于补充视觉表现。

## 玩法说明

项目中的蘑菇汤制作流程分为多个阶段：

1. 先加热到 1/4 进度
2. 加入蘑菇
3. 继续加热到 1/2
4. 进行第一次搅拌
5. 继续加热到 3/4
6. 进行第二次搅拌
7. 最后加热直到完成

整个流程由 `MushroomSoupGame` 中的状态机控制，只有在满足当前阶段条件后，才能进入下一步。

## 操作方式

- `Space`：增加火力
- `UpArrow` 或 `DownArrow`：加入蘑菇
- `LeftArrow` 和 `RightArrow`：完成一次搅拌

补充说明：

- 火力会随时间自动衰减
- 蘑菇只能在指定阶段加入
- 搅拌需要左右方向键都按到才算完成

## 运行逻辑

项目启动后，`MushroomSoupSceneBootstrap` 会先检查场景中是否已经存在 `MushroomSoupGame`。如果没有，它会自动完成以下工作：

- 创建或复用现有火焰特效
- 创建或挂接锅模型
- 生成汤面和汤体
- 创建搅拌勺
- 创建蘑菇动画的起点和落点
- 动态生成 UI Canvas、文本和进度条
- 最后创建 `MushroomSoupGame` 并把所有引用传入

之后 `MushroomSoupGame` 在每帧中持续处理：

- 玩家输入
- 火力衰减
- 烹饪进度推进
- 阶段切换
- 蘑菇投放动画
- 搅拌动画
- 汤面和锅的视觉反馈
- UI 内容刷新

## 当前项目特点

- 脚本结构集中，容易阅读和讲解
- 玩法闭环完整，适合展示
- 自动搭场景，减少手动绑定工作
- 即使部分资源缺失，也有基础几何体作为回退方案

## 当前限制

目前项目更像一个可运行的演示原型，还存在这些限制：

- 只支持一种固定菜品：蘑菇汤
- 输入方式写死在脚本中
- UI 为代码动态生成，不适合复杂菜单扩展
- 配方和流程是硬编码，后续扩展多个菜谱时需要重构
- 文本直接写在代码里，不利于多语言处理

## 后续扩展建议

如果后续继续完善，比较适合优先做下面几类扩展：

- 把菜谱、阶段目标、提示文本改成可配置数据
- 用 `ScriptableObject` 管理不同菜品规则
- 增加开始界面、完成界面和音效反馈
- 将传统 `Text` 组件逐步迁移到 TextMeshPro
- 把输入改造成可配置输入系统

## 快速上手建议

如果要快速理解这个项目，建议按这个顺序阅读：

1. 先打开 `Assets/Scenes/SampleScene.unity`
2. 查看 `Assets/Scripts/Cooking/MushroomSoupSceneBootstrap.cs`
3. 理解场景对象和 UI 是怎么生成的
4. 再看 `Assets/Scripts/Cooking/MushroomSoupGame.cs`
5. 重点理解状态机和 `UpdateCookingProgress()` 的推进逻辑

## 总结

这个项目本质上是一个基于 Unity 的“蘑菇汤交互制作演示”。它用较少的脚本完成了场景搭建、玩家输入、烹饪流程推进、动画反馈和 UI 展示，适合用于课程作业、项目答辩和后续二次开发。
